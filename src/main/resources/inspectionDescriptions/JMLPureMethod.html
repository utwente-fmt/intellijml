Reports code in a JML pure method that changes the state of the program, which a pure method may not do.

A pure method (also spec_pure, or pure because its class is pure or because it overrides a pure method) has an implicit assignable \nothing: it may only change its local variables and the objects that it creates itself. A pure constructor may also assign the fields of the new object. This inspection reports:

  • assignments, also with ++, -- and +=, to a static field, to a field of this, and to a field or array element of an object that existed before the call, such as a parameter or the value of a field;
  • calls of methods and constructors that are not pure and have no assignable clause, which may therefore change anything.

Example:


private int count;

//@ pure
public int next() {
    count++;            // a pure method may not assign to count
    return count;
}

OpenJML's type checking does not check this; Verify with OpenJML reports the same lines as violations of the assignable clause. This inspection does not know the specifications of the Java library, so it does not report calls such as list.add(x), and it does not compare assignable clauses.

A quick fix declares a called method pure, for a method that does not change the state but is not declared pure.
