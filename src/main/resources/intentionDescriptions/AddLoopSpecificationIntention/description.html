Adds the loop invariant and the decreases clause of a loop that counts by one, such as for (int i = 0; i < a.length; i++), or a while loop that does the same with one i++ in its body, or of a for-each loop over an array, with \count, the number of iterations done.

The invariant bounds the index, also after the last iteration, when it is one past the bound; the decreases clause shows that the loop ends. Add what the loop has done so far to the invariant, such as (\forall int j; 0 <= j && j < i; a[j] == 0). If the start may be past the bound, as in for (int i = 0; i < n; i++) with a negative n, the method needs a precondition such as requires n >= 0;. A loop such as for (int i = 1; i <= n; i++) does not end when n is Integer.MAX_VALUE, as i++ overflows, so OpenJML needs requires n < Integer.MAX_VALUE; for it.
