<!-- Plugin description -->
Provides support for the Java Modeling Language (JML) in IntelliJ IDEA, for students learning to specify and verify
Java programs:
- Checks JML specifications while you type, with the same errors as OpenJML, and syntax highlighting
- Code completion, live templates, and explanations of the JML keywords on hover
- Alt+Enter to add a specification skeleton, loop invariants and quick fixes
- Rename, Find Usages and Ctrl+click for the names in JML
- Run with JML Checks: runs programs and tests with run time checks of their specifications (OpenJML)
- Verify with OpenJML: proves that methods meet their specifications, with counterexamples and plain-word messages
